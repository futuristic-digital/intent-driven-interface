# Intent-Driven Interface (IDI)
## Brand matrix

| Element | Definition |
|---|---|
| **Mission** | Make software usable for everyone from day one, even if they’ve never used anything like it. |
| **Vision** | A world where everyone can use software with ease and understand what happens to their data. |
| **Values** | **Inclusion.** People can describe what they want to do in their own words, even if they’ve never used software like it. **Transparency.** People can see what’s happening to their data and look back to understand what changed and when. **Human control.** The person responsible for a decision makes it. Before they act, they can understand the consequences of their choice. |
| **Brand promise** | Say what you want to do in your own words. See the available options and exactly what each one does. You decide how to proceed. |
| **Positioning** | Intent-Driven Interface is a way of designing software around what people want to do. A person describes a task in their own words, and the interface brings up the tools to do it. |
| **Brand personality** | **Calm.** IDI shows only the components you need for the task. **Efficient.** IDI selects the component that best fits your intent and opens it with the relevant properties already set for you. **Direct.** In a few words, IDI explains why the selected component fits your task and points you to the feature to use. |
| **Tone of voice** | **Personal, plainspoken, and precise.** IDI uses “I” to explain what it opened and why. It speaks in your terms and names the feature to use exactly as it appears on screen. |
| **Audience** | People who design or build software and want anyone to find it easy to use from day one. |
| **Brand essence** | “I can use this.” |
